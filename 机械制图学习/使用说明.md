# 机械制图学习

快捷键：L画线，P标点，Ctrl+Z撤销，D删除选中的点和线；按住M临时测距，松开隐藏。点名输入期间不触发这些作图操作。重做已删除。

练习仅保留画线（L）、标点（P）两个模式，没有“选择”模式。点和线端点可以直接拖动；单击线身可选中，右键单击取消选中，右键拖动框选。画线单击已有端点仍可从该处开始新线。按住M临时用虚线、花括号及距离数字量取鼠标位置到两轴的距离，松开隐藏，不显示坐标值。输入点名时L、P、D、M作为普通文字，不切工具或开启测距。

双击本目录的 `开始学习.cmd`。首次启动稍慢，随后直接进入学习窗口，学习时无需打开 Blender 或 Godot 编辑器；字体、运行程序、题图和模型均在本目录，断网可用。

启动后先显示知识图谱，节点只用知识点名称。蓝色节点可点击，进入该知识点代表样例的自由观察；其他节点表示知识分支或标明“未制作”。实线箭头表示基础前置，虚线箭头表示建议先学的顺序，不限制进入任何已完成样例。鼠标滚轮围绕指针位置缩放，按住左键拖曳平移图谱；从节点上开始拖动也不会打开章节，单击才进入。

自由观察左上角的“知识图谱”返回图谱，章节选择统一在图谱中进行。返回后再次进入同一题，保留相机与对应点。拖动左侧模型旋转，滚轮缩放；“主视、俯视、左视”用于定向观察，“复位”恢复默认观察方向。

“点的三面投影”有“观察／练习／知识讲解”三个入口，进入章节默认观察。练习以第1套第一题的 A、B 两点为样例，只有题干和坐标纸，不预先显示答案或三维模型。默认画线：点起点，再点终点，右键单击取消未完成线段。标点模式单击放点，双击已放置的点弹出输入框，自由命名或修改名称；支持中文、字母和撇号，重名会提示，不覆盖其他点。未命名点也可保留。右键单击取消选中和未完成线段，右键拖动仍为框选。点和线端点可直接拖动。Ctrl+Z撤销，D删除选中的点或线；不提供重做。

练习滚轮绕指针缩放，空白处按住左键拖曳平移；端点拖动优先于平移。按住右键拖曳框选：框内的点及与框相交的学生线段会被选中，可批量删除，撤销一次恢复整批对象；坐标轴和45°线不能选中或删除。框选后切到“选择”仍保留所选对象，拖动某个端点仅修改那一个对象。

作图吸附到 1 mm，接近水平或竖直时有方向辅助。在画线、标点时，鼠标进入坐标纸就显示当前坐标，不必先点击。当前位置或选中端点到两条轴的距离用垂直虚线、随距离伸展的单边花括号和数字表示，单位为毫米；坐标带正负号，距离数字取绝对值。切换界面保留已完成草稿，取消未完成预览和框选框。草稿自动保存在 `%APPDATA%\Godot\app_userdata\机械制图学习\practice-v1.json`，重开后再次进入练习即可恢复。损坏文件保留并显示错误，不自动覆盖。

“知识讲解”是五步概念演示；练习里的“教学”是九步完整解题示范，每次从读题开始。两者独立全屏，只能退出或前后步进，动画期间不能步进，也不能操作模型和画布。教学使用画布中的示范光标，不控制系统鼠标；退出恢复自己的作图、选择和视野，不把示范写进草稿。知识讲解记住最后目标步骤，程序启动仍先显示知识图谱。

点击三维点、棱或表面，或右侧二维点和图线，会显示对应点标记。右侧按住图线或已有对应点拖动，标记可移到同一视图的任意实线、虚线或圆弧，不限制在最初点中的图线范围内，三维模型与另外两个视图中的标记同步移动。鼠标离开图线后，对应点仍跟随鼠标移动到最近的图线位置，松开结束拖动。图线和模型不再变色高亮。旋转三维模型不会触发选择。所有章节的投影辅助始终开启。

“原题”和“参考依据”打开原始图像，首次显示自动适合窗口。滚轮围绕指针位置缩放，按住左键拖曳平移；右上角“✕”关闭，不再显示滑动条或重复关闭按钮。学习模式始终显示完整投影。

第7项“全剖视：双孔连接件”使用第1套第五题（PDF第3页）。勾选“全剖”观察剖开的实体及主视图，取消勾选对照完整实体，视角保留。孔内留空，实体切面画剖面线，中间筋板纵向剖切时不画剖面线；俯、左视图仍画完整零件。关闭后会恢复该题的全剖选项。

形体图线按正常实线、虚线显示；浅灰跨视图长线用于对齐。以后开发做题模式时，待补部分完全隐藏，不显示灰色预告线。

切换例题保留各自观察位置；关闭窗口保存当前例题、视角和全剖显示选项。下次先进入知识图谱，点击相应样例恢复观察状态。旧存档中的步骤和隐藏基础投影的设置不再影响界面，相机位置保留。存档在 Windows 当前用户的 `%APPDATA%\Godot\app_userdata\机械制图学习\observation-v1.json`。测试使用另外的存档。

全剖视章节的“引导讲解”进入独立全屏演示。只有“退出、上一步、下一步”可操作；动画期间不能步进。退出恢复进入前的自由观察状态，不跳回知识图谱。

原题未标尺寸的例题使用教学比例，依据保留在资料与“参考依据”中。模型表达一种与原图相容的结构；尤其第六题孔与开槽相接处的内部深度采用教学设定，完整实体投影可能比原卷的简化线图多出隐藏细节，应同时打开参考依据核对。

当前包含六例投影与补视图、一个全剖视可行性样例，以及点章节的一例作图练习和概念讲解。没有评分、自动判定、随机出题或考试模式；其他章节尚无练习。其他剖视、相贯、标准件和零件图目前只做了资料归档。

需要继续制作时，先读 `开发说明.md` 与 `覆盖与核验.md`，再按根目录 `AGENTS.md` 查资料缓存。原经验手册保留。
